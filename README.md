# PY-CALCULTOR
Im Anay 15 years.
I built this simple command line calculator as my first project for Hack Club. It’s designed to handle basic arithmetic—addition, subtraction, multiplication, and division while keeping the code clean and easy to follow for other beginners and i have also added a invalid operations output if the input logic is not logicall for the python calculator
To run it, just make sure you have Python  installed on your computerrr, open your terminal or vs code or any other ide (VS is best), and run the script by clicking the run button . The program will walk you through entering your numbers and choosing an operation and the answer will showwwww (its so crazzy), and I’ve even included some basic error handling to prevent the program from crashing if you divide by zero.

Im excited to keep improving this my next goals are to add support for exponents and a history log for past calculations. If you have any feedback or ideas for new features, feel free to open an issue or reach out. Happy coding!
